# 메모리 1번 — COMMA ONE 모바일 메인 화면 PIXEL PERFECT 구현 지시

> 이 파일은 COMMA ONE 모바일 메인 화면 작업 시 **가장 먼저 읽어야 하는 절대 지시사항**이다.
> 모바일 메인 화면 관련 작업을 시작하기 전에 반드시 이 내용을 전부 읽고 그대로 따른다.

---

절대 새롭게 디자인하지 마라.
절대 네 판단으로 UI를 개선하거나 재해석하지 마라.
절대 비슷한 화면을 만드는 것으로 끝내지 마라.

첨부한 기준 이미지를 COMMA ONE 모바일 메인 화면의
"절대적 원본(Source of Truth)"으로 지정한다.

목표는 "비슷하게"가 아니라
기준 이미지와 실제 실행 화면을 픽셀 단위로 최대한 동일하게 만드는 것이다.

==================================================
## 2. 기준 화면
==================================================

첨부된 이미지를 기준으로 한다.

기준 이미지의 전체 화면 비율과 레이아웃을 먼저 분석하고
그 결과를 코드의 고정 기준값으로 만든다.

특히 다음을 먼저 측정한다.

A. 화면 전체
- viewport width
- viewport height
- 상단 safe-area
- 하단 safe-area
- 실제 콘텐츠 영역

B. 각 섹션
- 시작 Y
- 종료 Y
- 높이
- 좌우 margin
- 카드 간 gap

C. 모든 텍스트
- font-size
- font-weight
- line-height
- letter-spacing
- baseline 위치

D. 모든 컴포넌트
- width
- height
- padding
- margin
- border-radius
- shadow
- border

이미지에서 눈대중으로 추측하지 말고
가능한 값은 실제 픽셀 기준으로 측정해서 CSS에 반영한다.

## 4. "반응형"을 이유로 기준 화면을 변형하지 마라
==================================================

기준 화면을 먼저 정확하게 구현한다.

그 다음 다른 스마트폰에서도 깨지지 않도록
responsive 처리한다.

단,

responsive 처리 때문에 기준 화면의 디자인이 변하면 안 된다.

기준 viewport에서는
첨부 이미지와 동일하게 보여야 한다.

==================================================

MobileDashboard는 준비된 데이터를 받아서
기준 이미지와 동일하게 표시하는 역할만 한다.

==================================================
## 6. 기존 기능을 함부로 삭제하지 마라
==================================================

현재 동작하는 API와 상태관리 구조를 최대한 유지한다.

기존 기능을 삭제하거나 임의로 다른 API로 교체하지 마라.

필요하면 현재 데이터 구조를 유지하면서
화면 표시 구조만 기준 이미지에 맞춰 변경한다.

==================================================
## 7. 가장 중요한 검증 방법
==================================================

코드를 수정한 후 "완료"라고 하지 마라.

반드시 실제 브라우저에서 화면을 실행한다.

그리고 기준 이미지와 실제 실행 화면을 비교한다.

다음 순서로 검증한다.

1. 동일한 viewport 크기로 실행
2. 실제 화면 캡처
3. 기준 이미지와 비교
4. 차이가 있는 위치를 찾는다
5. CSS/구조 수정
6. 다시 캡처
7. 다시 비교
8. 차이가 없어질 때까지 반복

특히 다음을 집중 검사한다.

- 상단 로고 위치
- 첫 카드 시작 위치
- 카드 높이
- 카드 좌우 폭
- 카드 사이 간격
- 포착 종목 카드 높이
- 종목명 위치
- 현재가 위치
- 점수 원형 위치
- 미니 차트 위치
- 추천 카드 폭
- 검색 영역 높이
- 발굴 현황 아이콘 간격
- 브리핑 카드 높이
- 하단 메뉴 높이
- 전체 콘텐츠의 Y축 위치

==================================================
## 9. 완료 조건
==================================================

다음 조건을 모두 만족해야 완료다.

- [ ] 기준 이미지와 동일한 전체 레이아웃
- [ ] 동일한 섹션 순서
- [ ] 동일한 카드 크기
- [ ] 동일한 카드 간격
- [ ] 동일한 텍스트 위치
- [ ] 동일한 폰트 크기/굵기
- [ ] 동일한 색상
- [ ] 동일한 radius
- [ ] 동일한 shadow
- [ ] 동일한 아이콘 위치와 크기
- [ ] 동일한 하단 네비게이션
- [ ] 실제 데이터 연결
- [ ] 모바일 화면에서 스크롤 구조 정상
- [ ] 다른 모바일 해상도에서도 깨지지 않음

기준 화면과 차이가 남아 있으면 작업 완료로 보고하지 마라.

==================================================
## 10. 최종 원칙
==================================================

"기준 이미지 → 측정 → 코드 구현 → 실제 캡처 → 비교 → 수정 → 재검증"

이 순서를 반드시 반복한다.

이번 작업은 디자인 제안이 아니다.

첨부 이미지를 실제 COMMA ONE 모바일 메인 화면으로
코드로 재현하는 작업이다.

임의의 디자인 판단을 하지 마라.

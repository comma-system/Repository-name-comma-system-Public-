# 콤마365 유튜브 쇼츠 개선안 (@comma365kr)

> 기준: 2026-10-20 채널 Shorts 탭 화면 (동영상 8개, 조회수 7~47회)

## 1. 진단 — 왜 조회수가 안 나오나

| 문제 | 화면에서 확인된 내용 | 영향 |
|---|---|---|
| **제목·썸네일 중복** | "좋은 종목이면 지금 사도 될까?"가 4개 영상에 반복, 고층빌딩 배경도 3개 동일 | 유튜브가 비슷한 영상으로 보고 노출을 나눠 가짐. 시청자도 "본 영상"으로 넘김 |
| **제목이 잘림** | `…지금 사도 될까… \| 콤마365` → 핵심 단어가 뒤로 밀려 잘림 | 피드에서 클릭 이유가 안 보임 |
| **첫 1초 문구가 화면 밖** | 1번 영상 "~라 산다 / ~접수화" 글자가 좌측 잘림 | 첫 1초 이탈 → 알고리즘이 추천 중단 |
| **약한 훅** | "종목 추천, 그다음은?" 검은 화면 + 작은 글씨 | 스크롤이 멈추지 않음 |
| **사이트 유입 경로 없음** | 채널 링크가 `YouTube` 하나뿐, 설명에 comma365.co.kr 없음 | 봐도 프로그램으로 넘어갈 길이 없음 |
| **질문만 있고 답이 없음** | 대부분 "사도 될까?"로 끝남 | 시청 완료율·댓글이 낮음 |

**잘 된 영상:** "매도 타이밍, 팔아야 할까 버텨야 할까"(47회)가 1위 → **물려있는 사람의 '아픈 곳'(손절/매도)** 주제가 반응이 좋음. 이 방향으로 더 만들기.

## 2. 바로 할 일 (오늘, 10분)

### ① 채널 링크 추가 (가장 중요 — 쇼츠 설명란 링크는 클릭이 안 됨)
YouTube 스튜디오 → 맞춤설정 → 기본 정보 → **링크 추가**
- 링크 제목: `콤마365 무료로 써보기` / URL: `https://comma365.co.kr`
- "배너에 표시할 링크 수" → 1개 이상

### ② 채널 설명 교체
```

AI 주식 분석 프로그램 '콤마365'가 추천 이후의 결과까지 공개합니다.

▶ 프로그램 바로가기: comma365.co.kr
▶ 매주 월·수·금 쇼츠 업로드

※ 본 채널은 투자 참고용 정보이며, 투자 판단과 책임은 본인에게 있습니다.
```

### ③ 모든 쇼츠에 **고정 댓글** 달기 (댓글 → 고정)
```
📌 지금 보신 매수구간·목표가·손절가, 종목별로 바로 확인하세요
👉 comma365.co.kr (프로필 링크 클릭)
궁금한 종목 댓글로 남겨주시면 다음 쇼츠에서 분석해 드립니다!
```

### ④ 쇼츠마다 "관련 동영상" 연결
스튜디오 → 쇼츠 세부정보 → **관련 동영상** → 가장 조회수 높은 영상(매도 타이밍)으로 연결 → 영상끼리 시청이 이어짐.
